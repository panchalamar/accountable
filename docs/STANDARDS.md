Follow these coding guidelines:

- Be thoughtful, careful and consistent about naming things so that code is expressive and easy to read.
- Don't comment out unused code, delete it.
- Favor short functions and methods with one purpose.
- Make code readable so that only short comments are needed. Make comments about the why.
- Clean abstractions with clear separation of concerns, but don't abstract before it is needed.
- Avoid brittle tests that are tied to implementation specifics.
