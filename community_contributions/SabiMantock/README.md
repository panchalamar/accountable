# Accountable MVP: Sabi Mantock

My Week 1 Day 3 documents for the Accountable MVP, a sales CRM for one person running locally: dashboard, organizations, contacts, deals and a drag-and-drop pipeline, on React + Vite and FastAPI + SQLite.

- `intent.md`: the intent, after the intent interview
- `spec.md`: requirements with IDs, architecture, data model, API, screens and visual design
- `plan.md`: ten build phases, risks, and the tests that prove each spec ID
- `REVIEW.md`: the review policy

The design is mockup D, which combines one mockup's top bar and dashboard with another's pipeline board. The mockups and their screenshots are in [docs/mockups](https://github.com/SabiMantock/accountable/tree/main/docs/mockups).

The full build is in my fork: https://github.com/SabiMantock/accountable
