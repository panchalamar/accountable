# Accountable MVP: sarvjot23

A single-user sales CRM: a dashboard with charts and a sales funnel, organizations, contacts, deals, activities with follow-ups, and a drag-and-drop pipeline board. FastAPI and SQLite on the back end, React on the front end, with pytest, Vitest and Playwright tests behind one `npm test`.

These are the documents I wrote on Week 1 Day 3: `intent.md`, `spec.md`, `plan.md` and `REVIEW.md`.

The build is in my fork: https://github.com/sarvjot23/accountable
